# AI Campus Assistant — LangGraph with Conditional RAG

A college assistant chatbot built with **LangGraph** and **LangChain**. It does not send every question to the same place — a classifier node first reads the student's question and routes it:

- **Academic questions** (attendance, exams, grading, credits) → RAG over the academics handbook PDF
- **Fee questions** (tuition, refunds, late charges, scholarships) → RAG over the fee structure PDF
- **General questions** → answered directly by the LLM, no retrieval

Retrieval uses **FAISS** vector stores with HuggingFace embeddings (all-MiniLM-L6-v2), and answers are generated by **Google Gemini** through LangChain. The app is programme-aware: it highlights the rules and figures for the student's own programme (BCA / BBA / B.Com).

> Built as a course project while learning LangGraph, conditional routing and RAG patterns.

## Files

| File | What it is |
|---|---|
| `app.py` | Streamlit chat app — the full assistant with a web UI |
| `conditional_RAG.py` | The same LangGraph assistant as a command-line app |
| `academics_handbook.pdf` | Knowledge base for academic questions |
| `fee_structure.pdf` | Knowledge base for fee questions |

## How it works

1. PDFs are loaded with PyPDFLoader and split into chunks (800 characters, 100 overlap)
2. Each PDF gets its own FAISS index built from HuggingFace embeddings
3. A classifier node labels each incoming question academic, fee or general
4. A conditional edge routes the question to the matching retriever (top 4 chunks)
5. The response node answers from the retrieved context, or from general knowledge when no retrieval is needed

## Run it yourself

```bash
pip install -r requirements.txt
```

Create a `.env` file with your own Google API key (see `.env.example`):

```
GOOGLE_API_KEY=your_google_api_key_here
```

Then run the web app:

```bash
streamlit run app.py
```

Or the command-line version:

```bash
python conditional_RAG.py
```
